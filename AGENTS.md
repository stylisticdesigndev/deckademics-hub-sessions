# Architecture rules
- Store Music Production enrollments, curriculum, and module completion separately from DJ records so production levels never trigger DJ certificates or alter DJ assessment rules.
- Keep instructor DJ and Production dashboards and curricula on separate routes, independent of the student/admin program switch; database policies remain responsible for authorizing production changes.
- Store teaching-program assignments separately in admin-managed instructor_programs; ProtectedRoute resolves those assignments before rendering instructor pages so login and deep links use the correct program.
- Store flexible Production lessons as ordered typed JSON blocks; render Markdown without raw HTML and use private signed media URLs to prevent executable lesson content and public file exposure.
- Keep Production submissions, intake, catch-up packets, and session packages in enrollment-scoped tables; students submit pending work, staff verify it, and only admins create/link program enrollment.
- Derive Production session balances from purchased credits and unique present attendance dates from the first package start; absence never consumes a session, and renewals append credits rather than erase history.
